# Executive Producer — Golden Key Lead Conversion

Run one OpenMontage canonical chain:

`brief -> proposal_packet -> script -> scene_plan -> asset_manifest -> edit_decisions ->
render_report/final_review -> publish_log`.

Read the manifest, `director-decision-policy.md`, `reviewer-rubric.md`,
`meta/text-layer-direction`, fact-only `CustomerFactSet` offer inputs, PlatformProfile, material query, capability
context, and prior canonical artifacts before each stage. Do not create a Golden Key script,
shot plan, recipe, or reviewer beside OpenMontage artifacts.
Resolve and preserve the versioned `ProjectContentContext`, frozen source revisions, exact
multimodal citations, permissions, validity, conflicts, prohibited expressions, and gaps at
every stage. Empty selection forbids retrieval; benchmark fixtures never become customer facts.

Use OpenMontage's current meta capabilities directly: `meta/taste-direction` at proposal,
`meta/animation-runtime-selector` before runtime choice, `meta/bespoke-composition` when a
hero/atelier route is plausible, and `meta/voice-performance-director` whenever narration is
selected. They guide conditional choices and do not make animation, narration, or atelier
composition mandatory.

Gates:

1. Idea: correct route, target lead, verified offer/mechanism, qualification, proof, CTA.
2. Proposal: at least three real concepts, vetoes, objections, audio/text/support path.
3. Script: complete relevance-to-mechanism-to-proof-to-qualified-action narrative.
4. Scene: exact source ranges or explicit synthetic/support designation.
5. Assets: provenance, current offer/CTA, prompts, proof boundaries, audio, fallback.
6. Edit: exact timeline, claim-proof adjacency, semantic text layers, readable CTA ending.
7. Compose: technical, offer, proof, qualification, audio, platform, ending, disclosure QA.
8. Publish: truthful packaging with one verified and measurable next action.

Customer gates cover task understanding and the recommended conversion direction. Technical
gates map to the internal operator or system validator. Paid, reference-driven,
identity-sensitive, testimonial-sensitive, or claim-sensitive work uses the proposal sample
gate before batch generation.
