# Compose Director — Golden Key Product Marketing

Read `edit_decisions.render_runtime` and use the matching OpenMontage compose path. Pass the
proposal artifact so runtime-swap detection runs. Route approved captions/overlays through
FFmpeg, Remotion, or HyperFrames exactly as specified; never silently downgrade.

Mix narration/source speech, BGM, natural sound, and SFX according to the approved hierarchy.
Render only asset-manifest inputs. Verify output existence, ffprobe, complete decode,
duration/resolution/frame rate/audio, text wrapping/safe zones, product/service visibility,
logo/text/person/action preservation, claim/evidence adjacency, and generated disclosure.

Write schema-valid `render_report` and `final_review`. A provider or generation failure uses
the approved fallback or blocks; it cannot change the creative promise during compose.

Review the ending temporally, not from an evenly sampled contact sheet alone. Inspect the
render at approximately `duration-1.0s`, `duration-0.5s`, and `duration-0.1s`, listen through
the audio tail, and record `final_review.checks.ending_closure`. It passes only when the final
meaning is complete, the last text has readable clearance, the planned visual release is
visible, and music/natural sound does not truncate. A technically valid file with an accidental
hard stop must be revised before presentation.
