# Executive Producer — Golden Key Product Marketing

Run one OpenMontage canonical chain:

`brief -> proposal_packet -> script -> scene_plan -> asset_manifest -> edit_decisions ->
render_report/final_review -> publish_log`.

Read `director-decision-policy.md`, `reviewer-rubric.md`, `meta/text-layer-direction`, the
manifest, fact-only `CustomerFactSet`/profile/material/capability context, and prior artifacts before each
stage. Do not create a Golden Key script, shot, or recipe truth beside these artifacts.
Resolve and preserve the versioned `ProjectContentContext`, frozen source revisions, exact
multimodal citations, permissions, validity, conflicts, prohibitions, and gaps at every stage.
An empty selection forbids wider-library retrieval.

Use OpenMontage's current meta capabilities directly: `meta/taste-direction` at proposal,
`meta/animation-runtime-selector` before runtime choice, `meta/bespoke-composition` when a
hero/atelier route is plausible, and `meta/voice-performance-director` whenever narration is
selected. They enrich decisions but do not force those production layers.

Gates:

1. Idea: correct route, facts, audience, platform, source reality, truth boundary.
2. Proposal: 3+ real concepts, scoring/vetoes, selected production/audio/text/support path.
3. Script: complete fact-benefit-evidence story.
4. Scene: exact source ranges or explicit synthetic/support designation.
5. Assets: provenance, prompts/protection/fallback, finished audio plan.
6. Edit: full exact timeline and semantic text-layer validation.
7. Compose: technical, preservation, evidence, audio, platform, and disclosure QA.
8. Publish: truthful packaging and CTA.

Customer gates cover task understanding and one recommended direction. Technical checkpoints
map to internal operator or system validator. Reference-driven/high-cost/preservation-sensitive
work uses the proposal sample sub-stage before batch generation.
